# Upstream work

Speech Lab's own code is MIT licensed. Dependencies and model weights retain their upstream licenses; the repository does not redistribute weights or human recordings.

- **WavLM** — Microsoft, [code and paper](https://github.com/microsoft/unilm/tree/master/wavlm), [Base+](https://huggingface.co/microsoft/wavlm-base-plus), [Large](https://huggingface.co/microsoft/wavlm-large).
- **XLS-R** — Meta/Facebook, [model card and license](https://huggingface.co/facebook/wav2vec2-xls-r-300m).
- **Qwen3-ASR / Qwen3-Omni** — Qwen Team, [ASR](https://github.com/QwenLM/Qwen3-ASR), [Omni](https://github.com/QwenLM/Qwen3-Omni); checkpoint cards in [model notes](docs/models.md).
- **Speech Articulatory Coding** — Cheol Jun Cho and collaborators, [repository](https://github.com/Berkeley-Speech-Group/Speech-Articulatory-Coding), [checkpoint](https://huggingface.co/cheoljun95/Speech-Articulatory-Coding). `demos/articulation.py` reimplements its normalization, padding, WavLM feature selection, temporal filtering, and linear inversion. The upstream package declares MIT licensing; consult its distribution for current terms.
- **Praat / Parselmouth** — [GPL license](https://github.com/YannickJadoul/Parselmouth/blob/master/LICENSE), separately installed dependency.
- **PyTorch, Transformers, SciPy, scikit-learn, NumPy, SoundFile, FastAPI and other dependencies** — installed through `uv.lock` under their own licenses.

Synthetic examples are generated by this repository. The UI uses system font fallbacks and no remote font/CDN requests. Provider outputs are local user data and are not published with the source.
